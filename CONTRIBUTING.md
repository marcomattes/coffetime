# Contributing

Thank you for contributing. Open an issue before large changes, keep pull requests focused, and never commit private keys, production configuration, or databases.

1. Install PHP 8.2+, Composer, the OpenSSL and PDO SQLite extensions.
2. Copy `config.example.php` to `config.php` and generate a development key pair.
3. Run the checks documented in README before submitting a pull request.
4. Explain behavior and security implications in the pull request description.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
